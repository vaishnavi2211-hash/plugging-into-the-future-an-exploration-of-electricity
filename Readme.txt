# Electricity Consumption Data Analysis

A data analytics project focused on analyzing electricity consumption datasets using SQL, Python, and Tableau. The project includes interactive dashboards and visual reports for understanding consumption trends and patterns.

## Features

* Data cleaning and preprocessing
* SQL-based data analysis
* Interactive Tableau dashboards
* Data visualization with filters and calculated fields
* Public dashboard publishing using GitHub Pages

## Tech Stack

* Tableau
* SQL
* Python
* GitHub Pages
